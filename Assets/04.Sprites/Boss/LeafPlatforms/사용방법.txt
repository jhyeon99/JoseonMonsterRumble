잎·잎대 모듈 6종 / 배치 예시 9종

1. Sprites: 투명 PNG 6개와 Unity 가져오기 설정(.meta).
2. Prefabs: 잎 소·중·대 × 잎대 짧음·중간·김 = 9개 배치 예시.
3. 비교보기.html: 원본 PNG를 사용해 게임 크기 비율과 접합 위치를 보여주는 미리보기.
4. dimensions-and-attachment.json: 파일별 실제 해상도, 연결점, 배치 크기 기록.

이 폴더 전체를 Unity Assets 안으로 복사한 뒤 Prefabs의 예시를 배치하세요.
PNG와 .meta를 함께 복사해야 연결 기준점과 PPU 설정이 유지됩니다.
PPU는 전부 100입니다. 고해상도 PNG를 그대로 보존하고, 프리팹 내부 Leaf/Stem의 Scale로 크기를 맞췄습니다.
잎의 최종 가로 폭: 소 3.27 / 중 6.46 / 대 10.31 유닛.
위 폭은 제공된 예시 이미지의 보이는 발판 폭 약 327 / 646 / 1031픽셀을 PPU 100으로 환산한 시작값입니다.
기존 발판 오브젝트에 추가 Scale이 있다면 그 값도 반영해 최종 크기를 조절하세요.
잎대 길이 시작값: 짧음 1.4 / 중간 2.8 / 김 4.2 유닛.
잎 두께는 각각 0.50 / 0.55 / 0.60 유닛으로 낮게 잡았습니다.

접합 방식
- 잎 Pivot: 아랫면 중앙 접합부 끝.
- 잎대 Pivot: 윗면 중앙.
- 프리팹은 두 접합부를 0.04유닛 겹치고 잎을 앞에 그려 틈을 숨깁니다.
- 잎 크기에 맞춰 프리팹의 잎대 가로 굵기도 조절해 연결 부위를 맞췄습니다.
- 루트 오브젝트의 위치는 잎대 하단 지면 위치입니다.
- 전체 크기는 프리팹 루트 Scale로, 잎대 길이는 Stem 자식의 Scale Y로 조절할 수 있습니다.
- Stem 길이를 변경하면 Leaf와 Stem의 연결 위치도 함께 옮겨주세요.

프리팹은 시각 배치 예시입니다. 기존 게임 발판의 충돌 판정/레이어/동작은 별도로 연결하세요.
Sprite-Unlit-Default 머티리얼은 현재 프로젝트에 설치된 Unity URP 패키지 참조를 사용합니다.
투명 PNG, 메타데이터, 크기 환산 및 프리팹 파일 참조는 검사했습니다. Unity 에디터에서 실제 가져오기/플레이 검증은 수행하지 않았습니다.

생성 방식: 기본 image_gen 도구. PNG를 별도 이미지 처리로 변형하지 않고 원본 그대로 저장했습니다.
Unity PPU/Pivot 참고: https://docs.unity.com/en-us/engine/6000.0/manual/materials-and-shaders/textures/textures-reference/texture-type-sprite
